## WeSwitch v0.6.2

填地址和 Key 即可。能用 Key 拉到的模型列表会自动填上。

### 填写更少
- 只需要 API 地址和 API Key。点「获取模型列表」并确认后，用这把 Key 请求 `/models`，把返回的模型 ID 填进列表。
- 提供方名称和 ID 按地址自动补全。拉不到列表时仍可手写模型 ID。
- Key 仍只在你确认后发送，获取列表不会保存密钥。

### 选择器
- 勾选写入模型目录时，除 `models.json` 外，同步合并登录后桌面选择器渲染的 `models_cache.json`，并刷新缓存时间。
- 没有 `[desktop]` 时也会写入全部推理强度，避免所选档位被藏掉。
- 远程目录刷新仍可能盖掉缓存，需要再应用一次。Codex Desktop 自己的选择器过滤不在本工具范围内。

### 还原
- 目录备份按原路径退回，且只允许写在当前 Codex 目录内。
- 写入时拒绝符号链接目标。

应用后请完全退出 Codex（⌘Q）再打开。
