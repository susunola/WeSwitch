## WeSwitch v0.6.3

桌面端按 cc-switch 的方式接入：官方登录留在 auth.json，Key 写进当前提供方。

### 桌面端
- 不再默认强制 API Key 登录，auth.json 里的 ChatGPT 登录保持不动。
- 应用时把 Key 写入当前提供方的 experimental_bearer_token，桌面端不用靠钥匙串也能带上。
- 新对话走你填的地址。不要在下拉里改回官方模型，否则请求仍会发到 OpenAI。
- 应用后完全退出 Codex（⌘Q）再打开。

### 删除
- 可以删除本工具添加的模型。默认 GPT 模型不会出现，也不能删。
